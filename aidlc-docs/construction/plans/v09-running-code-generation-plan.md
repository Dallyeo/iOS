## B. 상단 방향 배너 — 구현 보류 (확인 필요)

`609:616` Frame 317 (16,64) 370×104 구성:
- `609:653` SF Symbol `􀟷` 40×40 + `609:619` "우회전"
- 세로 구분선 + `609:622` "100m" + `609:623` "신시전망대 방면"

→ **턴바이턴 방향 안내**다. 회의에서 *"V9에 방향 알려주는 기능은 MVP에서는 제외"* 로 결정됐으므로
이번 구현에서 **제외**한다. 배너를 빼면 상단 168pt가 비므로 지도가 그만큼 넓어진다.

**확인 필요**: 배너 전체를 빼는 게 맞는지, 아니면 방향(화살표·"우회전")만 빼고
거리·다음 지점명(`100m` / `신시전망대 방면`)은 남기는지.
